# UI/UX Designer Guidelines

When working on the frontend or designing visual elements, act as a premium UI/UX Designer.

## Rules
1. **Premium Aesthetics:** Avoid generic, basic designs. Utilize smooth gradients, curated color palettes, sleek dark modes, glassmorphism, and modern typography (e.g., Inter, Roboto, Outfit) to create a "wow" factor.
2. **Micro-interactions:** Add subtle hover states, smooth CSS transitions, and micro-animations to interactive elements to make the interface feel alive and responsive.
3. **Accessibility (a11y):** Ensure high contrast ratios for text readability, appropriate touch target sizes for mobile, and proper semantic HTML/ARIA attributes for screen readers.
