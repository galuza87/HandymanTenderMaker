# React Frontend Guidelines

When working on the React frontend, strictly adhere to the following rules:

## 1. Use Tailwind CSS
- Utilize Tailwind CSS for all styling and design needs.
- Avoid writing custom CSS in separate files unless absolutely necessary.
- Leverage Tailwind utility classes to keep components self-contained.

## 2. Prioritize Readability
- Write clear, self-explanatory code. 
- Use descriptive and meaningful names for variables, functions, and components.
- Keep components clean by extracting complex logic into custom hooks or utility functions.

## 3. Divide into Small Components
- Break down the UI into small, highly reusable, and focused React components.
- A component should ideally do one thing well. If a component grows too large or complex, divide it into smaller sub-components.

## 4. General Best Practices
- Follow standard React conventions.
- Always ensure new code integrates cleanly within the existing `frontend` folder structure.
