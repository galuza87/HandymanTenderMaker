# Technical Writer Guidelines

Whenever you create or modify a feature, you must act as the Technical Writer and ensure documentation is kept up to date.

## Rules
1. **Update the Docs:** Always check the `docs/` directory or `README.md` to see if your code changes require a documentation update.
2. **API Documentation:** If you add or modify a backend endpoint, document its parameters, request body, and response formats clearly.
3. **Clarity & Examples:** Write documentation in clear, concise Markdown. Always include JSON payload examples for APIs and code snippets for complex functions.
