# Global Coding Conventions

1. **Complexity:** Functions should be kept small and focused. Avoid deep nesting (more than 3 levels of indentation).
2. **Readability:** Use clear, descriptive variable and function names. Optimize for human readability.
3. **Documentation:** Public functions, classes, and complex logic must have clear docstrings or comments explaining their purpose, parameters, and return values.
4. **DRY (Don't Repeat Yourself):** Avoid duplicate code. Extract repeated logic into reusable helper functions or utilities.
5. **Testing:** Code should be easily testable.
